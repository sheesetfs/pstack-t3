- kind feature
- `install` writes a Claude Code `SessionStart` hook whose script prints a short note telling each new chat when to enter `poteto-mode`, and records the entry in the install manifest with the checkout that installed it, so `uninstall` removes that exact entry and nothing else in `settings.json`, and a run from another checkout leaves it and that checkout's skills alone. The optional `sessionHook` key in the roles file takes `true` or `false`, `false` silences the note, and `roles.py validate` rejects a value that is not a boolean. `doctor` names an entry that is missing, duplicated, stale, or under a matcher `install` did not write, and `install` repairs a drifted matcher. A settings file whose `hooks` value holds another shape refuses the run before any step runs.
